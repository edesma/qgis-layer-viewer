# Examples

Sample files for testing **QGIS Layer Viewer**. Each dataset was prepared in QGIS
and exported as a `.qlr` Layer Definition file, paired with its GeoJSON data where applicable.

## How to use

1. Open [QGIS Layer Viewer](https://geo.edesma.org/qgisviewer/index.html)
2. Use the drag-and-drop interface — each file combination below corresponds to one of the two load options

## Files

| File(s) | Load option | Source |
|---|---|---|
| `Bicycle Ramps.geojson` + `Bicycle Ramps.qlr` | GeoJSON + QLR | City of Denver |
| `Denver Neighborhoods.geojson` + `Denver Neighborhoods.qlr` | GeoJSON + QLR | City of Denver |
| `Neighborhood Commute Bike-Walk (%).geojson` + `Neighborhood Commute Bike-Walk (%).qlr` | GeoJSON + QLR | U.S. Census |
| `Neighborhood.qlr` | QLR + web URL | City of Denver |
| `Denver Facilities.geojson` + `Denver Facilities.qlr` | GeoJSON + QLR | OpenStreetMap |
| `Pub Transp (%).geojson` + `Pub Transp (%).qlr` | GeoJSON + QLR | U.S. Census |
| `Denver-Facilities-Web-Geojson.qlr` | QLR + web URL | City of Denver |
| `Denver Bicycle Facilities.qlr` | QLR + web URL | City of Denver |
